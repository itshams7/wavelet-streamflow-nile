# Data Access

Raw discharge data is not redistributed in this repository, in line with GRDC's data policy.

To reproduce this project's data:

1. Register for a free account at the Global Runoff Data Centre (GRDC): https://www.bafg.de/GRDC/EN/Home/homepage_node.html
2. Request monthly discharge data for the following stations:
   - Khartoum (Blue Nile, Sudan)
   - Sennar (Blue Nile, Sudan)
   - Roseires (Blue Nile, Sudan)
   - Dongola (Main Nile, Sudan)
   - Malakal (White Nile, South Sudan)
3. Place the downloaded files in this `data/` folder before running the notebook.
